초기 범위에 포함하지 않는 기능

온라인 결제, 실시간 코트 예약, 레슨 출결·회비 정산, 자체 채팅, 문자·알림톡, 원본 영상 자동 영상 변환. 필요해지면 별도로 범위와 비용을 결정합니다.

상담 문의 방식은 아직 정하지 않았습니다.

‘상담 문의’ 버튼의 목적지는 아래 두 방식 중 결정합니다. 일반 방문자의 상담 접수와 동호회 회원 가입·승인은 별도 흐름입니다.

안 A · 연락처 접수 후 코치가 전화

방문자가 회신받을 연락처와 필요한 상담 내용을 남김 → 코치가 접수 확인 → 해당 연락처로 전화. 선택 시 수집 목적·보유 기간·처리 담당자·삭제 방식과 문의 관리 화면을 설계합니다. 회원 가입에 전화번호를 필수로 추가한다는 뜻은 아닙니다.

안 B · 오픈카톡으로 상담

상담 버튼 → 운영자가 준비한 오픈카톡 링크 → 외부 채팅에서 상담. 방의 공개 범위·운영 시간·응대 담당자를 결정합니다. 홈페이지 자체 채팅을 만드는 안은 아닙니다.

현재는 연락처 입력 폼·실제 오픈카톡 링크·상담 접수 기능을 만들거나 연결하지 않았습니다. 선택 후 상세 기능·개인정보 처리·운영 비용을 확정합니다.

공개 갤러리 운영안 · 보기와 올리기는 다릅니다.
누가할 수 있는 일
비회원·가입 대기·거절·정지 상태게시 완료 사진과 지원하기로 한 영상 열람, 안내된 연락 경로로 삭제 요청
승인 회원공개 열람 + 본인 사진 기록 작성·업로드·공개 요청·수정본 제출·삭제 요청. 영상은 지원 결정 시 포함. 다른 회원 기록 수정 불가
코치·운영자인물 동의·내용 확인, 공개 승인·숨김·삭제 처리. 일정·참가자·계정 정보는 공개 갤러리에 넣지 않음

사진은 비회원 공개이며, 영상도 지원한다면 비회원 공개 방향입니다. 영상 기능 지원 여부 자체는 아직 미정입니다. 코치 심사 후 게시하고 수정본을 다시 확인하는 절차는 운영 제안입니다. 공개 동의를 거절해도 회원 일정 이용은 가능하며, 그 사람이 드러나는 자료를 그대로 게시하지 않습니다.

사진·영상 삭제 요청도 비회원에게 열어 둡니다.

갤러리·개인정보 안내에 담당 연락처를 표시합니다(연락처·처리 기한은 출시 전 결정). 요청자가 자료의 주소를 알려주면 운영자가 최소한의 확인 후 노출 중지 → 사진·썸네일 삭제 → YouTube 채널 담당자 조치 → 처리 결과 회신 순으로 대응합니다. 공개 게시물이나 댓글로 신분 증빙을 받지 않습니다. 이 연락 경로는 아직 미정인 레슨 상담 방식과 별도로 정합니다.

목록에서 숨겨도 공개 사진 URL·캐시가 바로 사라지지는 않습니다. 파일과 썸네일도 삭제하고 지원되는 캐시 정리를 확인합니다. 외부에 복사·재공유된 사진이나 검색 기록까지 완전히 회수할 수 있다는 약속은 하지 않습니다.

공식 단가와 산식 자세히 보기 · 직접 보관는 기본 보관 상품 전용

유료 사진·회원 서비스 = $25 + max(평균 저장GB−100,0)×$0.0213 + max(일반 전송GB−250,0)×$0.09. 캐시 전송은 사용하지 않는 가정이며 실제로는 별도 250GB와 $0.03/GB 항목입니다. 회원 자료·처리 성능·추가 서비스 초과분은 계산하지 않습니다.

영상 직접 보관 = ceil(max(평균 저장GB−10,0))×$0.015 + ceil(max(쓰기 요청−1,000,000,0)/1,000,000)×$4.50 + ceil(max(읽기 요청−10,000,000,0)/1,000,000)×$0.36. 인터넷 전송비 $0. 무료분은 같은 계정의 다른 사용량과 공유될 수 있으므로 여기서는 다른 사용량 0을 가정합니다.

운영비를 줄이는 방법

작은 파일을 필요한 만큼만 보여줍니다.

새로고침 몇 번이 곧 큰 청구로 이어지지는 않습니다. 다만 사진이 커지거나 반복 조회가 많아지면 무료 한도를 소진할 수 있어, 처음부터 사용량을 줄이고 점검할 기준을 정합니다.

① 소개·가격은 가볍게

자주 바뀌지 않는 안내는 미리 만든 페이지로 제공합니다. 방문할 때마다 회원 자료를 불러오는 작업을 줄입니다. 검색엔진도 소개와 가격을 쉽게 읽을 수 있게 합니다.

② 사진은 작게, 필요할 때만

목록에는 작은 미리보기 사진만 보여주고 큰 사진은 눌렀을 때 엽니다. 사진은 자동으로 크기를 줄이고 한 번에 20개씩 보여줍니다. 예: 30KB 미리보기 20장을 새로 100번 받으면 약 60MB, 300KB 큰 사진이면 약 600MB입니다.

③ 이미 받은 자료는 재사용

기기와 가까운 서버에 잠시 보관한 복사본을 재사용합니다. 수정하면 새 자료가 보이도록 갱신합니다. 사용자가 캐시를 지우거나 여러 번 요청하면 다시 전송될 수 있으므로 사용량을 완전히 없애는 방법은 아닙니다. 공식 안내 [13]

1. 동영상 지원 여부부터

사진과 동영상 함께 지원

활동 분위기와 움직임을 더 잘 남길 수 있습니다. 촬영·등장 인물 동의·업로드·원본 관리가 추가되므로 실제 사용할 계획과 담당자가 필요합니다.

추천: 영상 활용 계획이나 담당자가 아직 없으면 사진만 먼저 시작합니다. 정기적으로 촬영하고 관리할 사람이 정해져 있다면 영상도 지원하는 편이 좋습니다. 현재 선택은 미정입니다.
